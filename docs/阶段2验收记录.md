# 阶段 2 验收记录

验收日期：2026-10-12（Asia/Shanghai）。范围：后端认证、RBAC、会话撤销及资源访问校验。

## 实现结果

- 登录、当前身份和退出接口，BCrypt 密码验证及账号状态校验。
- JWT HS256 签名验证、必需声明及有效期检查，MySQL 登录会话支持撤销。
- ADMIN / LEGAL / EMPLOYEE 角色，接口和方法双层授权，管理员用户管理及角色分配。
- 部门范围校验；申请按本人或本人待办限制查询，无权读取他人申请。
- 空用户库初始化管理员，重启不会覆盖已有账号；保护最后一名有效管理员。
- V3 增量迁移增加 auth_session，保留 V1/V2。

## 实际执行

环境：Windows、PowerShell 7、Java 25.0.4.1（编译目标 21）、Maven 3.9.6、MySQL 8.0.46。

执行 `pwsh -NoProfile -File scripts/verify-stage2.ps1`。使用新的独立 MySQL 数据目录和随机回环端口，创建测试库及单独的空认证验收库，未修改已有 MySQL 服务或真实用户数据库。验证结束停止脚本启动的应用与数据库。

Maven verify 成功，12 个测试全部通过，无失败、错误或跳过：

| 测试类 | 数量 | 验证内容 |
| --- | --- | --- |
| AuthIntegrationTest | 5 | 登录成败、多会话/退出、角色刷新/方法授权、禁用删除、无效令牌、部门与申请隔离 |
| DefaultSecurityIntegrationTest | 2 | 默认关闭临时 CRUD、数据库健康检查 |
| UserCrudIntegrationTest | 4 | 真实 MySQL 用户读写、校验约束、迁移和临时 Basic 认证 |
| SecurityConfigurationTest | 1 | 临时模式配置约束 |

AuthIntegrationTest 的无效令牌覆盖篡改签名、格式错误、过期、发行者错误、缺失到期声明及未注册会话。资源测试包含同部门其他员工不能读本人申请、LEGAL 未获分配不能访问、分配 PENDING 任务可访问、任务完成后不能继续访问。

真实 HTTP 验收通过：默认无认证拒绝、阶段 1 基础 CRUD 回归、初始管理员登录及 ADMIN 角色、员工管理接口拒绝、管理员创建用户与调整角色、同一令牌获取最新角色、退出后的旧令牌拒绝。应用重启后原管理员令牌有效，修改初始化密码配置没有覆盖已有密码。随机密码、签名密钥和实际访问令牌均未出现在验收日志。

验收脚本输出 `STAGE2_VERIFIED` 和 `STAGE1_VERIFIED`。最终复验路径：`.cache/stage1-c96a45d8ca0d4fafa3ef853330116601/`；测试报告：`backend/target/surefire-reports/`。复验包含禁止移除、删除和禁用最后管理员的断言。这些为本地忽略的产物，不作为源代码提交。

## 使用边界

启动必须注入 JWT_SECRET 和数据库凭据，首次管理员配置见 [后端说明](../backend/README.md)。本次初始化管理员发生在隔离验收库，未在用户实际业务库创建账号。旧阶段 1 库已有用户时需受控赋予管理员角色，初始化器不会自动提升账号。

前端尚未联调认证；当前申请详情为权限边界接口，申请提交及审批流程后续实现。没有刷新令牌、密码重置、登录限流、会话清理或生产部署验收。生产 HTTPS、数据库 TLS、密钥持久化及迁移账号分离需在部署阶段验证。

工具链出现 JDK 25 下 Maven/Mockito 动态代理兼容提示，未影响本次构建和测试。当前未把 JDK 21 本机运行视为已验证。
