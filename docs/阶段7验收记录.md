## 发现与修复

首次模型单测在沙箱内因回环套接字禁止而失败；使用获准的隔离本地服务验收环境运行后通过。第一轮完整测试发现直接调用受方法安全保护的 Controller 缺少测试身份、空依据路径未给 mock 模型提供名称；补齐测试身份和模型元数据。随后故障重试夹具用 when 重新设置已抛异常的 mock 时触发旧异常，改为 doReturn，补充冲突保存与未引用依据撤权用例后完整重跑成功。这些失败属于测试环境/夹具，不作为业务成功证据。

已有 Flyway 次数断言随 V7 更新；新增 questions GET/POST 安全门禁，继续保留接口方法权限和 MySQL ACL。解析/检索旧接口的默认行为保持兼容；受限响应体处理器增加可配置上限，默认仍为原解析上限，模型使用 64 KiB。
