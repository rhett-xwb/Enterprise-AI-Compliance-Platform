# 阶段 7 接口与权限说明

日期：2026年10月12日。已实现问答与历史链路；根据用户选择，模型通过可配置的 Chat Completions 兼容接口接入，真实生成模型尚未配置。

## 请求与结果

所有接口要求 Bearer JWT 和 `document:read`。记录仅归提问者所有，ADMIN 也不能读取他人的问答。

| 方法与路径 | 行为 |
| --- | --- |
| POST `/api/questions` | `{"question":"出差前需要办理什么手续？"}`，非空、最多 500 字符 |
| GET `/api/questions?before=<id>&size=20` | 本人历史，按 ID 倒序；before 排他，size 1–50 |
| GET `/api/questions/{id}` | 本人历史详情，重新检查全部检索依据的访问范围 |
| GET `/api/questions/{id}/citations/{citationId}` | 重查历史权限后返回当时真实引用快照 |

详情包含 id、question、status、answer、citations、model、embeddingModel、elapsedMs、errorCode 和 createdAt。引用为 `{id,source,state}`；source 包含阶段六 Hit 的文档名称、版本号、文本块 ID、真实页码/段落、章节、偏移和原文。引用 ID 是单次问答中从 1 开始的编号，不是数据库文本块 ID。Word 的 pageNumber 保持 null。

| 状态 | 解释 |
| --- | --- |
| ANSWERED | 模型返回回答且编号校验通过；是否忠实于条款仍需质量评估 |
| INSUFFICIENT | 无检索命中，或模型判断资料不足；采用服务端固定说明 |
| CONFLICT | 模型报告冲突，至少提供两个有效引用；由法务判断适用关系 |
| FAILED | 检索/模型失败、限流、超时、无效结果或生成期间来源变化；可再次提交 |
| RESTRICTED | 展示历史时任一依据已删除或无权限，隐藏整段答案和全部引用 |

业务失败保留记录并返回 HTTP 200 + FAILED，前端显式展示“问答未完成”。问答关闭返回 503，不创建记录；四个本机并发槽满返回 429。非法输入 400，他人记录/无权来源 404，未认证 401、缺少权限 403。

## 检索与模型边界

固定 topK=5、minScore=0.5，复用阶段六 MySQL 权限与有效版本过滤、Python 中文向量检索及返回校验。不发送完整库、他人历史、用户身份或密钥给模型，仅发送问题和当次授权命中的编号/正文。无资料时不调用模型。

system 提示明确将问题与文档视为不可信资料，不执行其中指令、不采用外部知识、不作审批决定。模型必须输出严格 JSON：status、answer、citations。拒绝多余字段、重复 JSON 字段、尾随内容、未知状态、非整数/重复/不存在引用、缺少编号标注、编号与数组不一致、超长回答及截断完成状态。服务端从原文组装来源，不接收模型编造的标题、页码或链接。页面按纯文本插值显示，不渲染模型 HTML。

这些检查能验证结构与引用存在性，不能证明每句话被条款支持，也不能保证任意模型抵抗提示注入或识别所有冲突。真实模型需使用质量问题集逐条人工核对。

模型返回后再次用新事务核对全部输入依据仍为当前授权的真实文本块，变化则丢弃答案，保存 SOURCE_CHANGED，无敏感原文。远程调用期间不持有数据库事务；不自动重试收费模型调用，也不复用旧问答作为当前依据。

## 历史来源保存

V7 新增 policy_question 表，在一次事务内保存问题、结果、全部检索依据快照、所用引用编号、模型标识、耗时和失败类型。引用快照独立于可重建的 document_chunk，不给历史引用建立指向可删除 chunk 的外键；索引重建仍可定位当时的块 ID、原文、版本与偏移。

历史详情根据数据库实时角色/部门检查全部依据，不采用管理员治理权限绕过范围。权限撤回或文档删除时隐藏整段回答，避免通过未引用但已输入模型的资料泄露信息。仍有权访问的旧版、停用、过期或未就绪版本保留快照并标记 OUTDATED；CURRENT 仅表示版本当前适用，不表示历史快照就是重建后的同一块记录。下载使用阶段四文件接口，重新授权。

历史列表只显示本人问题、原状态、时间；它不包含答案与制度名称。旧答案不用于新问答。服务端不主动擦除已经显示在浏览器中的内容，下次访问重新检查。

## 模型配置

```text
QA_ENABLED=true
QA_COMPLETIONS_URL=https://your-provider.example/v1/chat/completions
QA_MODEL=your-model-name
QA_API_KEY=通过本地环境或密钥管理注入
QA_TIMEOUT_SECONDS=60
```

默认 QA_ENABLED=false。URL 是完整 POST 地址；远程必须 HTTPS，回环本地服务允许 HTTP；无重定向。API key 非空时发送 Bearer；本地免认证服务可以留空。模型名最多 255 字符。超时 1–120 秒，HTTP 连接超时 5 秒、响应体最多 64 KiB、temperature=0、max_tokens=2000、stream=false。兼容服务必须返回 choices[0].finish_reason=stop，message.content 是上述 JSON 字符串。未依赖供应商特有的 response_format。不会在日志中记录问题、原文、模型答复或凭据。

更换生成模型后重新评估答案、冲突与注入；Embedding 仍使用阶段六固定标识，不因更换生成模型重建向量。该阶段不新增 SDK 或外部编排框架。

失败代码：MODEL_NOT_CONFIGURED、MODEL_RATE_LIMITED、MODEL_TIMEOUT、MODEL_INTERRUPTED、MODEL_UNAVAILABLE、MODEL_RESPONSE_INVALID、RETRIEVAL_UNAVAILABLE、SOURCE_CHANGED。服务端数据库写入失败沿用统一异常处理；不声称有宕机续跑、客户端超时后的幂等提交或自动去重。
