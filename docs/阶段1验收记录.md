数据库集成测试使用真实 MySQL，不以 H2 替代。检查包含重复用户名、无效参数、Unicode 密码字节上限、未知字段、不存在部门、跨文档版本指针与引用归属约束。

第一次验收发现 JDBC 写入后 MyBatis 在同一事务中读取了缓存的旧用户状态。已将用户修改和软删除统一通过 MyBatis 更新，使缓存正确失效；再次执行完整验收通过。MySQL CHECK 约束错误按真实驱动错误码 3819 核对。

脚本最终输出 `STAGE1_VERIFIED`，随后停止自己启动的应用和测试数据库。另执行 PowerShell 语法检查及 `git diff --check`，均通过。
