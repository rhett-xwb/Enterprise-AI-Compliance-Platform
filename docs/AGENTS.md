# 项目协作约定

## 开发记录

- 完成重大功能、架构、权限、数据库、依赖或部署改动时，同步维护 `docs/DEVELOPMENT_LOG.md`。
- 记录实际实现、验证结果和遗留事项，区分已完成、待验证和后续计划，不将页面骨架或模拟数据写成业务已完成。

## 阶段学习笔记

- 按用户要求，每次阶段开发交付时，自动生成或更新 `My_Learning/stage<N>_note.md`，无需用户再次提醒。阶段内分批开发时持续更新同一份笔记，说明本次进展与尚未完成内容。
- 沿用 `stage1_note.md`、`stage2_note.md` 的中文学习笔记风格：主题、日期、阶段目标、生活场景类比、分节说明、必要的表格或流程，以及“有什么用”“后续怎么用”和当前边界。
- 说明做了什么、为什么按这个顺序开发、核心概念如何工作，以及它们与 Java 后端知识和下一阶段的关系；提供项目中的具体例子与代码阅读入口。
- 验证内容以实际执行记录为准，引用对应阶段验收文档；仅整理笔记时不要声称重新执行了业务测试。
- 同步记录笔记交付到开发日志，最终回复提供笔记文件链接。历史阶段笔记保留其当时的语境，不因后续实现完成而静默重写历史。
