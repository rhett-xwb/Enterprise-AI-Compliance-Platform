# 阶段 8 差旅申请与 AI 预审

日期：2026年10月12日。首条流程由用户确认为差旅申请。沿用 JWT、统一响应与 `approval:submit` 权限，所有读写仅限本人申请；ADMIN 无额外读取他人申请权限。阶段二只读的 `/api/approval-requests/{id}` 保留原有本人/待办范围，完整差旅接口使用以下路径。

## API

| 方法与路径（前缀 `/api/travel-requests`） | 输入与行为 |
| --- | --- |
| POST `/` | Form：title、destination、startDate、endDate、purpose、amount；创建 DRAFT，版本 1 |
| GET `/` | before 默认 Long.MAX_VALUE，size 默认 20，1–50；本人按 ID 倒序游标分页 |
| GET `/{id}` | 表单、版本、状态、活动附件、最新 20 次预审、提交编号/版本/时间 |
| PUT `/{id}` | `{contentVersion, form}`；锁定申请，核对草稿及版本，版本加一，旧分析 STALE |
| POST `/{id}/attachments` | multipart file + contentVersion；上传后版本加一，旧分析失效 |
| DELETE `/{id}/attachments/{attachmentId}` | query contentVersion；软移除、版本加一，旧分析失效 |
| GET `/{id}/attachments/{attachmentId}` | 本人活动附件下载，attachment、no-store、nosniff |
| POST `/{id}/reviews` | `{contentVersion}`；确定性规则、授权检索、可配置生成、保存前复核版本与依据 |
| POST `/{id}/submit` | `{contentVersion, reviewId}`；当前版本最新预审、规则再次检查、原子快照/审计/SUBMITTED |

日期使用 `YYYY-MM-DD`；金额固定人民币 CNY，非负数、最多两位小数，草稿允许金额和必填内容暂缺；正式提交必须金额大于零、标题/目的地/事由非空、起止日期完整且结束不早于开始。标题最长 255、目的地 200、事由 3000 字。非法金额、参数或文件返回 400；版本变化、已提交、旧/失败预审返回 409；本人范围外返回 404；未登录 401，无操作权限 403。

附件最多 10 个，每个非空且不超过 10 MiB，复用阶段四 PDF/DOCX/PNG/JPG/JPEG 文件校验；保存随机存储键、真实文件名、SHA-256、大小与 MIME，不对客户端暴露存储键。附件加入版本表示加入时刻，当前完整附件集合以活动记录为准；提交快照保留确切附件编号与散列。移除附件保留文件及历史记录，物理清理后续实现。上传事务回滚时移除新文件。

## 预审结果与风险边界

Review 包含 id、contentVersion、status、riskLevel、issues、advice、evidence、citations、model、errorCode、analyzedAt。issues 是可验证的表单/日期/金额规则问题；advice 是带编号的制度解释与修改建议，citations 为 evidence 中从 1 开始的编号；出处由实际检索组装。规则问题来自系统字段要求/配置，不能伪装为制度原文。

| 状态 | 解释与提交行为 |
| --- | --- |
| REVIEWED | 有引用的建议，仍须人工核对 |
| UNKNOWN | 未启用模型、无授权依据或模型返回不足；明确无法判断，规则无误可提交待人工处理 |
| CONFLICT | 模型报告至少两条引用的冲突，交法务确认；规则无误可提交 |
| FAILED | 模型或检索故障；可重试，不可据此提交 |
| STALE | 表单或附件修改，原内容预审失效，不可提交 |
| RESTRICTED | 输入依据中任一来源已撤权/删除，隐藏全部建议及引用，不可提交 |
| SOURCE_OUTDATED | 输入依据已换版、退役、过期或不再 READY，不可提交，需重新预审 |

HIGH 仅表示确定性规则发现表单问题；UNKNOWN 表示没有足够依据；REVIEW_REQUIRED 表示建议需人工核对。当前没有由模型判定的 LOW/MEDIUM/HIGH 分类器，不以“生成成功”表示风险低或审批通过。

预审复用 `QA_*` 与 `RETRIEVAL_*` 配置；QA_ENABLED=false 时确定性规则和无依据记录仍能运行。`TRAVEL_MAXIMUM_AMOUNT=0` 默认关闭业务金额上限；正数启用部署配置规则，超过上限阻止提交。此值不是正式制度阈值，必须由管理员根据业务核实后设置；无任何硬编码示例上限。AI 只收到表单与附件文件名，不读取附件正文，页面明确要求人工检查附件。全部外部资料仍受阶段七系统提示和引用校验约束。

## 一致性与后续审批

每次修改使用申请行锁与 expected contentVersion。外部模型调用在事务外，完成后新事务锁定申请，检查是否仍是同一草稿版本，并复查全部制度依据。并发修改导致 409，不能落入新版本。预审限四个本机并发调用。

提交锁定同一申请，检查当前最新预审与规则，然后同事务保存 request_submission 的表单/币种/活动附件/预审编号快照、approval_action 的 SUBMIT 记录，并推进 SUBMITTED。唯一 request_id 阻止重复提交；提交后所有编辑、附件增删和预审均拒绝。此阶段未创建 workflow_instance/approval_task，没有自动批准或人工审批节点。阶段九将以提交快照启动流程版本。

分析与完整依据快照存入预留 ai_analysis_record.result_json，历史引用不依赖可重建 document_chunk 的外键，不启用 ai_citation。读取历史复查所有输入依据；修改后的 STALE 仍保留历史原因，撤权时即使是旧分析也隐藏建议与引用。提交记录只向本人返回元数据，完整快照保存在数据库供后续工作流使用。

本机附件存储沿用 DOCUMENT_STORAGE_ROOT；无新增依赖，V8 增量迁移，V1–V7 未修改。未验证生产多节点限流、真实模型质量、附件 OCR、撤回/退回重提、文件垃圾回收、已有库升级或生产部署。
