# 阶段 4：制度文档与版本管理验收记录

日期：2026年10月12日（Asia/Shanghai）。

## 实现范围

实现制度创建与文件上传、新版本上传、角色与部门范围、授权查询和下载、发布替换、停用、逻辑删除和操作记录。前端制度查询和管理页面调用真实后端接口，不再是待开放骨架。

支持 PDF、DOCX、PNG、JPG、JPEG；单文件最大 10 MiB，整个请求最大 11 MiB。文件名与内容格式校验、DOCX 解压限制、图片像素限制和下载 SHA-256 校验详见 [接口说明](./阶段4接口与权限说明.md)。

FileStorage 提供存储抽象，LocalFileStorage 默认写入 Java 工作目录下的 data/documents，可由 DOCUMENT_STORAGE_ROOT 配置固定目录。原文件与逻辑制度分开，版本不可覆盖；服务端路径不通过 API 返回。

## 验收环境与执行

执行前端 `npm run build`，以及项目根目录 `pwsh -NoProfile -File scripts/verify-stage4.ps1`。脚本使用本机 MySQL、随机回环端口、独立数据库和文件目录，先执行 Maven 验证，再启动打包后的应用与 Vite，最后执行 Chromium 测试并停止自身进程。没有操作现有业务数据库。

V4 增量新增实际发布时间与审计表；V1–V3 保持不变。后端未新增运行时第三方依赖。

## 检查内容

| 范围 | 验证内容 |
| --- | --- |
| 文件 | PDF、DOCX、PNG、JPEG 上传成功，伪装类型、空文件与超限被拒绝，响应不暴露存储路径 |
| 元数据 | 版本号唯一、有效期检查、分页参数与员工发布权限 |
| 数据权限 | 草稿隔离、角色与部门组合、法务本人治理、管理员治理、范围变更后重新授权、无角色配置默认拒绝 |
| 下载 | 原字节一致、no-store、未授权返回 404、损坏摘要返回 503、路径穿越被拒绝 |
| 发布 | PENDING 拒绝、READY 但无索引拒绝、未来和过期版本拒绝、重复发布不重复审计 |
| 版本 | 新版发布旧版 RETIRED/INACTIVE、当前有效集合唯一、历史原文件保留并可按最新权限下载 |
| 停用/删除 | 清空当前指针、当前查询排除、逻辑删除访问拒绝，数据库版本与操作记录保留 |
| 事务 | 主动回滚后文件与元数据清理；两个同版本及不同版本发布并发执行后仅一个当前版本 |
| 浏览器 | 员工查询与下载、法务上传草稿/新版本/编辑范围/删除、管理员发布/旧版历史下载/停用，以及移动端无页面横向溢出 |
| 真实 HTTP 超限 | 伪装 PDF 返回 400，大于 10 MiB 的 multipart 文件返回 413 |
| 回归 | 认证、菜单、权限变更、退出、断网恢复与阶段 1 CRUD |

普通上传、列表、下载、范围编辑、发布、停用、删除均使用真实 HTTP 和 MySQL。发布测试中的 READY 与 INDEXED 是隔离数据库夹具：阶段 5/6 尚未实现，夹具不作为生产能力，也没有业务接口允许手动伪造处理成功。
