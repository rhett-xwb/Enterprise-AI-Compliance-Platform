# 阶段 3：前端基础验收记录

验收日期：2026年10月12日（Asia/Shanghai）。

## 实现范围

在已有 Vue 3、Vite、Element Plus 与 Vue Router 工程上接入 Axios，使用同源 `/api` 代理调用真实 Spring Boot 后端。新增登录、工作台、角色菜单、用户列表、权限拒绝和后续业务页面骨架，替换原演示首页与说明页。

| 能力 | 实际行为 |
| --- | --- |
| 登录 | 调用 login 后读取 me，成功进入工作台；账号错误显示统一提示 |
| 会话 | sessionStorage 保存本标签页令牌，刷新恢复；密码不持久化 |
| 权限 | 页面导航重新请求 me；菜单根据权限集合显示，用户管理额外要求 ADMIN |
| 退出 | 调用 logout 撤销当前后端会话，成功后清理本地状态；网络失败可重试 |
| 接口异常 | 401 返回登录页；403、404、网络、服务错误提供明确提示 |
| 用户列表 | 真实分页查询，提供加载骨架、空结果、刷新和失败重试 |
| 页面骨架 | 制度、申请、审批与合同显示待开放说明，不调用尚未实现的业务 API |
| 布局 | 桌面侧栏，移动端横向滚动菜单；支持减少动画偏好 |

## 运行方式

详见 [前端说明](../frontend/README.md)。后端账号按 [阶段 2 接口说明](./阶段2接口与权限说明.md) 初始化，不提供共享默认密码。

默认 `/api` 代理到 `http://127.0.0.1:8080`，可通过前端 `.env.local` 中的 `API_PROXY_TARGET` 调整。开发服务与 preview 均仅监听回环地址。正式部署需同源网关代理及 HTTPS。

## 验收方法

执行 `npm run build` 和 `pwsh -NoProfile -File scripts/verify-stage3.ps1`。后者沿用阶段 1/2 的独立 MySQL 数据目录、随机端口和随机密码，并增加真实 Vite 服务与 Chromium 浏览器。结束后停止脚本创建的进程，不修改现有业务数据库。

浏览器验收覆盖：

1. 未登录访问受保护路由、错误密码、管理员登录、真实用户列表、刷新恢复、退出后旧令牌被拒绝。
2. EMPLOYEE 登录及对应菜单、前端用户管理拒绝、直接请求后端返回 403、390px 移动端无横向溢出。
3. LEGAL 登录及对应菜单、同样的前后端越权阻断和移动端检查。
4. 列表加载、空结果、500 错误、重试恢复，以及无效令牌返回登录。
5. 登录请求断网提示、恢复后重试，以及外部回跳地址被限制为工作台。
6. 已有会话身份查询断网后恢复、退出请求失败后保留会话并重试撤销。
7. 后端将法务角色改为员工后，下一次导航刷新菜单并阻断原制度管理访问。

身份、用户查询、角色修改、退出与权限拒绝使用真实后端。空结果、500、加载等待和断网通过 Playwright 拦截受控复现；无效令牌由真实后端拒绝。JWT 自然到期由后端回归覆盖，浏览器用无效令牌验证 401 处理路径，没有等待 900 秒自然到期。

## 已知限制

- Element Plus 保持全量注册，构建有超过 500 kB 的分块提示，不影响验收；按需加载后续优化。
- 用户页面本阶段提供查询；账号创建、更新与角色分配仍可使用现有后端 API，未在本阶段增加管理表单。
- 当前没有刷新令牌、密码重置或生产部署；角色菜单和页面骨架不能代表制度及审批业务已完成。
- 本次为本机 Chromium 验收，未执行 Firefox、Safari 或生产网关环境测试。
